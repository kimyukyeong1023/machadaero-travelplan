# 마차대로 여행계획 (machadaero-travelplan)

로그인 없이 관광지를 검색하고 상세정보를 확인할 수 있는 여행계획 프로젝트입니다.
로그인한 사용자가 자신의 여행계획을 만들고, 관광지를 계획에 추가해 방문 일정과 메모를 관리하는 서비스를 목표로 합니다.

## 20260918까지

- 관광정보 API를 이용한 키워드 검색, 검색 결과 페이징 및 관광지 상세 조회 구현.
- 카카오 로그인, 세션 기반 로그인 유지 및 로그아웃 구현.

- 메인, 로그인, 계획 목록·생성·상세 화면의 기본 구조 구성.

## 20260919 작업

- 여행계획 삭제 시 하위 일정을 먼저 삭제하도록 변경하여 외래 키 오류 해결, 트랜잭션 적용.
- 메인 화면 구조 정리 및 로그인·검색 버튼 연결. 검색 결과를 유지하며 항목 아래에 상세정보 표시.
- 관광지 검색은 25개씩 받아 5개씩 표시하고, 페이지 번호를 최대 5개씩 제공. 새 묶음만 추가 조회하고 이전 결과는 재사용.
- 계획 목록은 로그인 사용자의 계획 DTO 전체를 받아 JS에서 10개씩 표시하도록 변경. 상세 일정은 목록 조회에 포함하지 않음.
- 전체 / 예정·진행 중 / 지난 여행 / 날짜 미정 분류 적용. 시작일 오름차순으로 정렬하고 시작일이 없으면 하단에 표시.
- 계획 생성·수정 시 종료일이 시작일보다 빠르면 저장을 차단하고, 오류 안내와 입력값 유지.
- 계획 목록의 CSS 분리, 기능별 JS 정리 및 설명 주석 추가. 조회·날짜 검증 테스트와 JS 동작 검증 수행.

## 남은 확인 사항

- 검색한 관광지를 계획에 추가하는 화면 연결.
